## Product Definition
Build LinguaNova as a **digital headquarters**, not a brochure. It should function as:
- primary communication platform;
- client-acquisition channel;
- knowledge hub;
- educational resource;
- demonstration of LinguaNova expertise;
- future gateway to client portals, learning systems, research tools, publishing, community collaboration, and secure exchange.

Core governing principle: **Every page should teach something.**

## Brand
- Legal name: LinguaNova Group
- Public brand: LinguaNova
- Classification: Language Innovation Company
- Working tagline: Language. Intelligence. Innovation.
- Brand promise: Help people and organizations communicate, learn, and innovate through language and artificial intelligence.
- Internal motto: Technology with language. Language with purpose.
- Personality: intelligent, trustworthy, innovative, approachable, curious, compassionate.
- Voice: professional, friendly, confident, clear, educational, inclusive.
- Avoid: buzzwords, overpromising, fear marketing, empty AI clichés.
- Visual palette: Deep Navy, Teal, White; Warm Gray secondary; Soft Gold sparingly.
- Typography: Montserrat headings, Source Sans 3 body, Merriweather occasional accent.
- Logo: use the LinguaNova logo asset extracted from the Master Plan unless a later approved master logo file supersedes it.

## AI Website Assistant
The Master Plan calls for AI throughout the website, not only on an AI page.

### MVP
Current prototype:
- FAQ guidance;
- service/solution routing;
- consultation-preparation assistance;
- basic privacy warning;
- human handoff through consultation CTA.

### Production evolution
- multilingual AI chatbot;
- intelligent FAQ assistant;
- consultation triage;
- knowledge search;
- document-submission assistant;
- service recommendation;
- appointment scheduling;
- seamless escalation to a human specialist.

### Guardrails
- do not expose API keys client-side;
- do not accept confidential/sensitive documents in ordinary chat;
- use secure document exchange for protected materials;
- restrict answers to approved LinguaNova knowledge where appropriate;
- clearly distinguish informational guidance from regulated professional advice;
- retain human oversight.

## Decision Rule
Every future feature or page should answer:
- Does it improve communication?
- Does it create educational value?
- Does it use AI ethically?
- Does it strengthen trust?
- Would LinguaNova still be proud of it in ten years?
- Does it contribute to the mission?

If most answers are no, do not build it.
